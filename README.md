# 🎉 Event & Decoration Website

A modern and responsive **Event & Decoration Website** developed to showcase event decoration services, stage designs, gallery items, and various decoration concepts in an attractive and user-friendly interface.

## 📌 Project Overview

This website is designed for an event decoration/service business to showcase its creative designs and services online.

Visitors can explore different decoration categories, view gallery items, learn about available services, and contact the business through the website.

## ✨ Features

* 🏠 Modern and attractive Home Page
* 📖 About Us section
* 🎊 Event Decoration Services
* 🎭 Stage Designs
* 🪔 Oil Lamp Designs
* 🌸 Table Decorations
* 🚪 Entrance Decorations
* 🙏 Pirith Stage Designs
* 🖼️ Image Gallery
* 📞 Contact Page
* 📱 Responsive Design
* 🎨 Custom UI Design
* 🧭 Easy Navigation

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/pamudimaleesha/eventMysite.git
```

### 2. Open the Project

Open the project folder in **Visual Studio Code**.

### 3. Run the Website

Open `index.html` in your browser.

For a better development experience, you can use the **Live Server** extension in VS Code.
